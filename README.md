# FGO Motion Autofill

[@wiki版 FGOモーションテンプレート](https://w.atwiki.jp/siroi_human/pages/337.html) を参考に、入力フォームから貼り付け用の@wiki記法を自動生成するツールです。

## 主な機能

- Battle Character（第1～第3段階）の入力
- スキル使用1～3の入力
- Buster / Arts / Quick 各1～3、EX、宝具モーションの入力
- 各モーションのHit数入力
- 「1行＝1工程」から `→` と `&br()` を自動生成
- 通常モーションと差分モーションを別ブロックとして出力
- 生成結果のクリップボードコピー
- `localStorage` を利用した入力内容の保存・復元
- スマートフォン向け表示対応

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. そのページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をページへそのまま貼り付けます。
4. ページを保存すると入力フォームが表示されます。

> @wikiの `javascript` / `js` プラグインは、管理者のみ編集可能なページで利用してください。

## 使い方

1. 各欄へモーション情報を入力します。
2. モーション欄では、工程ごとに改行します。
3. Hit数欄には数字だけを入力します。
4. 「@wiki記法を生成」を押します。
5. 「生成結果をコピー」を押し、対象のサーヴァントページへ貼り付けます。

### 入力例

```text
敵へ接近する
剣を振り下ろす 2Hit
後方へ跳んで元の位置へ戻る
```

生成時には、次のような@wiki向け表記へ変換されます。

```text
敵へ接近する →&br()剣を振り下ろす 2Hit →&br()後方へ跳んで元の位置へ戻る
```

## 差分モーション

初期状態では「モーション一覧」と「第3再臨以降」の2ブロックを生成します。差分が不要な場合は「差分モーションのブロックも出力する」のチェックを外してください。ブロック名は自由に変更できます。

## 保存

「入力内容を保存」で、同じブラウザの `localStorage` へ入力内容を保存します。@wiki記法を生成した際にも自動保存します。
