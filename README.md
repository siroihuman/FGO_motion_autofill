# FGO Motion Autofill

[@wiki版 FGOモーションテンプレート](https://w.atwiki.jp/siroi_human/pages/337.html) を参考に、入力フォームから貼り付け用の@wiki記法を自動生成するツールです。

## 主な機能

- Battle Character（第1～第3段階）の入力
- スキル使用1～3の入力
- Buster / Arts / Quick 各1～3、EX、宝具モーションの入力
- 各モーションのHit数を複数行で入力
- モーションの各工程とHit数を行単位で対応
- Hit数へ `Hit` を自動付与（`2` → `2Hit`、`1+2` → `1+2Hit`）
- 「1行＝1工程」から `→` と `&br()` を自動生成
- 通常モーション1つ＋差分モーション最大3つを個別ブロックとして出力
- 生成結果のクリップボードコピー
- `localStorage` を利用した入力内容の保存・復元
- スマートフォン向け表示対応

## @wikiへの導入

1. @wikiで、この機能を置く専用ページを作成します。
2. そのページの編集権限を「管理者のみ編集可能」にします。
3. `atwiki_paste.txt` の内容をページへそのまま貼り付けます。
4. ページを保存すると入力フォームが表示されます。

> @wikiの `javascript` / `js` プラグインは、管理者のみ編集可能なページで利用してください。

## 使い方

1. 各欄へモーション情報を入力します。
2. モーション欄では、工程ごとに改行します。
3. Hit欄もモーションと同じ行番号に対応させて入力します。
4. Hit欄には `2` や `1+2` のように入力します。`Hit` は生成時に自動で付きます。
5. Hitがない工程はHit欄を空行にして位置を合わせます。
6. 「@wiki記法を生成」を押します。
7. 「生成結果をコピー」を押し、対象のサーヴァントページへ貼り付けます。

### 入力例

モーション欄：

```text
敵へ接近する
剣で2回斬る
魔力を放つ
```

Hit欄：

```text

2
3
```

生成時、モーション列とHit列は次のように対応します。

```text
敵へ接近する →&br()剣で2回斬る →&br()魔力を放つ
&br()2Hit&br()3Hit
```

Hit欄には複数行を書けます。`2+3` のような内訳も1行に入力でき、`2+3Hit` として出力されます。すでに `Hit` を付けて入力した場合は重複して付与しません。

## 差分モーション

通常モーションに加えて、差分モーションを最大3つまで生成できます。

- 差分1：初期状態で有効
- 差分2：必要な場合のみ有効化
- 差分3：必要な場合のみ有効化

各差分は個別に出力ON/OFFを切り替えられ、ブロック名も自由に変更できます。

## 保存

「入力内容を保存」で、同じブラウザの `localStorage` へ入力内容を保存します。@wiki記法を生成した際にも自動保存します。

v1.0で保存した通常モーションと差分1の入力データは、そのまま復元できるよう保存キーを維持しています。
